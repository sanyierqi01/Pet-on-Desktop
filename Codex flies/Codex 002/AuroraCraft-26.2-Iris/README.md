# AuroraCraft 26.2 Iris

AuroraCraft is a lightweight Iris shaderpack for Fabric clients. It focuses on
soft directional shadows, cleaner water, material-aware block rendering, and
more atmospheric clouds and weather.

Install:

1. Put `AuroraCraft-26.2-Iris.zip` in `.minecraft/shaderpacks`.
2. Start Minecraft with Fabric + Iris.
3. Select `AuroraCraft 26.2 Iris` from Video Settings > Shader Packs.

Notes:

- Built with the common Iris/OptiFine shaderpack layout for broad compatibility.
- If your target Minecraft version is written as `1.26.2`, this pack should still
  be treated as an Iris shaderpack rather than a mod jar.
- For best shadows, set shadow quality to 1x or higher in Iris.

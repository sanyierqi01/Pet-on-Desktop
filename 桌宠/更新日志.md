# 更新日志

## 2026-09-19

### 新增

- 桌宠渲染拆分为独立的身体层和人脸层，人脸不再和身体绘制在同一张图像中。
- 人脸库保存在 `assets/faces`，原照片提取出的人脸已设为默认人脸。
- 新增 `人脸管理.exe`，提供人脸列表、预览、上传、切换和删除功能。
- 上传照片后调用 Windows 自带的离线人脸检测能力，自动识别人脸并裁切为透明头像。
- 桌宠每秒检查人脸库状态；更换当前人脸后无需重启即可更新。
- 右键菜单新增“开机自动启动”。
- 转向疲劳时显示半闭眼、垂眉、叹气嘴和汗滴表情。

### 改进

- 爬行动作改为 16 帧对角四足步态。
- 上臂和前臂分段运动，支撑、回拉、抬爪和前伸动作更加清楚。
- 自动爬行会朝鼠标方向移动，并根据鼠标位置自动镜像转身。
- 启动器增加单实例保护、错误提示和桌面/开始菜单快捷方式。
- 修复独立人脸层和身体层的坐标原点不一致问题，头部位置现在与肩颈严格对齐。
- 修复无 PowerShell 7 环境下中文脚本加载失败的问题，EXE 现在可回退到 Windows PowerShell 5.1。

### 文件

- `桌面宠物.exe`：启动桌宠。
- `桌面宠物.exe --face-manager`：从统一入口打开人脸上传与管理界面。
- `assets/faces/library.json`：记录全部人脸和当前默认项。
- `assets/faces/default.png`：默认人脸。
- `assets/layers/body.png`：不含脸部的透明身体层。
- `assets/layers/face.png`：不含身体的透明人脸层。
- `scripts/detect-face.ps1`：调用 Windows 离线人脸检测。
- `scripts/face-library.ps1`：负责人脸识别裁切、保存、切换和删除。
- `ui/face-manager.xaml`：人脸管理界面布局。

### 验证

- 原照片离线检测结果：识别到 1 张人脸。
- 默认人脸路径：`assets/faces/default.png`。
- 桌宠静态预览、疲惫表情预览和 16 帧爬行动作预览均已重新导出。
- `桌面宠物.exe` 已成功编译，桌宠模式和人脸管理模式均通过启动测试。
- `人脸管理.exe` 已合并到 `桌面宠物.exe`，不再需要单独程序。
- 已用 Windows PowerShell 5.1 验证桌宠和人脸管理界面的回退启动。
- 已检查实时透明窗口，确认 EXE 可见且人脸、身体图层对齐。
- 人脸裁切已改为 WPF 图像管线，不再依赖朋友电脑可能缺失的 `System.Drawing.Common` 程序集。
- 新增 `release\桌宠-便携版.zip`，解压后可直接运行，不需要额外安装开发环境。
